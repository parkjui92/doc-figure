# 해외 보고서의 그래프·구조도 벤치마크 (2026-11)

doc-figure v2.2의 근거 문서. board로 그린 도식 후보를 사용자가 "유명 리포트들 찾아보면 그래프나 구조도 멋진 게 많다"며 거부하고(2026-11-20), 국내 공공기관 디자인 보고서 한 건(2026)을 기준 예시로 든 데서 시작했다. 해외 보고서와 그래프 작성 지침서 29건을 공식 누리집에서 받아 그림 140장을 잘라 재고, 유형별로 나눴다. 그림 원본과 PDF는 저작권 때문에 저장소에 넣지 않는다(로컬 `_private/benchmark-2026-11-intl/`, git 제외). 여기에는 측정값과 규칙만 남긴다.

> [benchmark-kr-2026.md](benchmark-kr-2026.md)(국내 공공 도식 57장 + 사용자 채택본 43장)는 상자에 글이 여러 줄 들어가는 **체계도·절차도**의 문법이다. 이 문서는 그 문서를 대체하지 않는다. 국내 벤치마크에 거의 없던 두 갈래 — **수치를 보이는 그래프**와 **모양이 뜻을 나르는 디자인 보고서풍 구조도** — 를 더한다. `house`·`house-report`의 금지 규칙(그라데이션·입체 금지)은 그대로이고, 디자인 보고서풍은 별도 프리셋 `design-report`로만 그린다.

## 2. 수치로 본 생김새

잣대는 [benchmark-kr-2026.md](benchmark-kr-2026.md) §2·§2a와 같다(그림 긴 변 900px, 세 채널 모두 242 이상 = 흰 바탕, 채널 차 28 이상 = 유채색, 명도 120 미만에서 글자 획을 지운 면 = 진한 면). 글자는 PDF 글자 조각의 실제 pt이고, 그림 폭으로 나눠 16cm 폭에 넣었을 때로 환산했다(글자가 그림 파일 안에 든 것은 빠짐 — 그래프 83장·구조도 47장).

- **그래프는 구조도보다 훨씬 희다.** 흰 바탕 85~93%가 흔하다(강조 선 93% · 아령 92% · 점 그림 93%). board용 경고선(흰 바탕 85% 초과 = 휑함)을 그래프에 대면 잘 만든 그래프가 걸린다 — 그래서 `--verify`는 그래프에 따로 잣대를 쓴다(흰 바탕 95% 초과 · 색 면적 0.8% 미만 · 진한 면 12% 초과만 경고)
- **진한 면은 거의 없다.** 그래프 91장 중 12%를 넘는 것은 5장, 구조도 49장 중 7장. 넘는 것은 띠 전체를 칠한 순위표, 남색 누적 막대, 층 구조도처럼 면이 곧 자료인 그림이다
- **글자**: 해외 원본의 그림 안 글자는 5~9pt로 작다(WEF 7pt, Stanford 5.2~6.7pt, IPCC 6.5~7.5pt, Deloitte 8.2~9.2pt, ITU 8.4~11.5pt). 16cm로 환산한 본문 중앙이 그래프 7.6pt·구조도 8.1pt인데, 한글은 같은 pt에서 획이 많다. 크기 값이 아니라 **비율**을 가져온다 — 제목은 그림 안 글자의 1.4~1.5배, 큰 숫자는 두세 배. viz 는 본문 약 8.5pt·최소 7pt 이상으로 고정했다(지침서: IPCC 9~11pt, 줄여도 9pt 아래로 내리지 않음)
- **폭**: B 묶음 50장 중 49장, C 묶음 38장 중 37장이 본문 단 폭 전체다. 높이는 폭의 0.6~1.0배(중앙 0.74)

## 3. 반복해서 보인 것 — 그래프

괄호 안은 근거 장수(묶음 A 그래프 31 · B 31 · C 22, 지침서는 쪽).

1. **강조색 하나(많아야 둘)와 회색.** 말하려는 대상만 색을 주고 나머지는 같은 회색으로 둔다(Draghi 13장 중 8장). 분류가 없는 그래프는 한 색 또는 한 색의 진한 것·옅은 것(A 31장 중 15장). 색상 셋 이하가 B 31장 중 약 20장. 회색 분포 위에 강조 점만 두 색으로 칠한 그림(WIPO)은 색 면적 0.3%로 묶음에서 가장 적은데 강조가 가장 또렷했다
2. **순서가 있는 값은 한 방향 농도, 방향이 둘인 값은 두 색.** 단계·응답 강도·구성비는 같은 색의 농도 단계(A 4 · B 6장), 늘어남과 줄어듦은 서로 다른 두 색(A 3장). 서로 무관한 다섯 색을 단계에 쓴 그림은 순서가 색으로 읽히지 않았다. 지침서: 순차 자료는 한 색상 5단계 이하, 무지개 척도 금지(IPCC p.9~12, EU 출판국 p.18·23)
3. **같은 대상은 문서 끝까지 같은 색.** WEF 위험 분류 다섯 색, Brookings 지역 유형 여섯 색, Draghi의 EU·미국·중국(5장 모두), 넷제로 사회 7장 모두
4. **범례보다 직접 이름표.** 이름과 값을 선 끝·막대 안·점 옆에 적는다(A 31장 중 22장 · B 13장 · C 22장 중 11장, Draghi 선 그래프 4장 모두). 겹치면 가는 지시선으로 벌린다. 범례만 둔 그림은 선과 이름을 오가며 읽어야 했다. 지침서 둘이 직접 이름표를 권한다(IPCC p.15·19, EU 출판국 p.23·28)
5. **눈금선은 없거나 옅은 가로선 한 종류.** A 31장: 없음 14 · 옅은 선 17. B 31장: 없음 11 · 옅은 가로선 9 · 점선 7. Draghi 13장은 전부 없음. 진한 격자는 0장. 값을 막대 끝에 적은 그림은 축까지 뺀다(ITU 3장). 회색 바탕에 흰 눈금선(JRC 4장)은 무거웠다
6. **값 순서로 줄 세우고 기준은 따로 표시한다.** 나라·기관을 견주는 막대 6장 모두 값 순서. 기준값은 점선·띠·표식(평균 행, 50% 점선). 지침서: 순위가 요점이면 정렬, 막대의 축은 0에서 시작(FT p.1)
7. **주석은 한두 곳, 말하려는 차이에만.** 차이값을 원 안 큰 숫자로(IRENA), 격차를 세로 화살표와 숫자표로(Draghi 13장 중 4장), 영역을 옅게 칠하기(WEF), 세로 점선과 짧은 글(Nesta). 주석이 열 곳을 넘는 그림은 한 쪽에서 읽기 어려웠다
8. **결론은 한 줄로 어딘가에 적는다.** 제목이 결론 문장인 것: A 8장(Deloitte·Brookings) · B 18장(OECD·IPCC·UNDP·세계은행) · C 0장. 제목은 명사구로 두고 결론을 따로 한 줄 둔 방식도 있다(IEA — 그림 바로 아래 색 글씨 두 줄). 지침서 둘은 요점을 말하는 제목을 권한다(EU 출판국 p.27 — 10낱말 미만, IPCC p.19). 국내 보고서는 `<그림 n>` 명사구 제목이 관례이므로 **발주처 양식을 따르고, 결론은 그림 아래 한 줄(`conclusion`)이나 그림 위 한 줄(`takeaway`)로** 둔다
9. **제목은 위 왼쪽, 자료 줄은 아래 왼쪽.** 번호 줄 → 굵은 제목 → 옅은 단위 부제 → 그림 → 자료(A 45장 중 43장, B 50장 모두, Draghi 13장 모두). 캡션을 아래에 둔 기관도 있다(NIST·넷제로·CSIRO) — 위치는 양식이 정한다
10. **그림을 본문과 가르는 것은 테두리가 아니라 옅은 바탕 상자나 여백.** 옅은 회색 상자에 제목·출처까지 넣은 것 A 26장(WEF·Deloitte·Nesta), 흰 바탕에 굵기와 여백으로만 가른 것 16장(Stanford·Brookings·CSIS)

## 4. 반복해서 보인 것 — 구조도

1. **두세 가지 색과 회색, 면은 옅게.** 구조도 A 14장 중 12장이 세 색 이하, B 19장 중 11장, C 16장 중 8장이 한 색 계열의 농도 2~3단계. 진한 칠은 머리띠·번호 원·가운데 상자 한 곳(진한 면 중앙 1.7%)
2. **짙은 머리띠 + 옅은 몸.** 표 모양 구조도 C 6장, B 4장. 칸을 선으로 두르지 않는다 — 국내 벤치마크의 '두 층 채움'과 같다. 세계은행의 틀 그림(열 머리띠 셋 + 왼쪽 이름표 열 + 흰 카드)은 국내 체계도와 구성이 가장 가까웠다 → board가 이미 그린다
3. **형태가 관계를 말한다.** 줄어드는 것은 깔때기(2장 + 기준 예시), 둘러싼 것은 고리(4장), 겹치는 것은 원(3장), 갈라지는 것은 벌어지는 경로(2장), 싸여 있는 것은 커지는 호(1장 + 기준 예시)
4. **큰 숫자 묶음.** 수치 몇 개가 곧 메시지일 때 숫자를 본문 글자의 두세 배로(15~27pt, 3장 + 그래프 안 부품 2장). 숫자마다 무엇의 숫자인지와 한 줄 설명
5. **아이콘은 글과 함께, 한 가지 양식으로.** 아이콘을 쓴 C 7장 모두 글 이름표가 붙었고, B 11장은 원 안에 한 색 아이콘. 화살표는 가는 실선·점선
6. **그라데이션·입체는 드물고, 쓸 때는 뜻이 있다.** A: 양 끝이 반대인 스펙트럼 2장과 회색 막대 1장. B: 3장(등각 블록·카드·경로). 기준 예시(국내 디자인 보고서)는 깔때기·원·고리에 부드러운 그라데이션과 타원 테를 쓰되 **옅은 가로 띠 위에 도형 하나씩**이고, 팔레트는 청록·남색 두 축에 주황 한 점이다

기준 예시에서 가져온 형태 — 언제 쓰는가 · 모양이 하는 주장

## 6. 따라 하지 않은 것

- **작은 글자**(5~7pt) — 영문 원본 크기 그대로는 한글로 읽기 어렵다
- **범례만 있는 여러 색 선 그래프**, 가는 막대 100개 이상, 색상 다섯 이상 — 표본 안에서도 읽기 느렸던 것
- **회색 바탕 + 흰 눈금선**, 이중 축에 눈금 둘(지침서: 이중 축·3D 금지 — EU 출판국 p.20·22). `bar-line` 은 선 쪽 눈금을 그리지 않고 값을 점 위에 적는다
- **등각 투영 그림 · 지도 · 산점도 · 사진 합성** — 코드로 그리지 않는다(유량도·연결도·연결망은 v2.2.1부터 그린다. 연결망은 힘 배치가 아니라 타원 고정 배치다 — 놓인 자리에 뜻이 없다). 필요하면 이미지 모델 경로로 가고 글자·수치는 코드 렌더와 대조한다
- **장식이 내용보다 큰 그림**(사진 콜라주 연표 등) — 표본에 견줄 예로만 넣었다

## 7. 한계

- 표본은 공개 PDF 29건에서 고른 140장이다. 컨설팅사(McKinsey·BCG·PwC·Bain)와 IMF·GAO는 접속 차단으로 빠졌다. The Economist·Our World in Data는 공개 PDF가 없어 보지 않았다
- 보고서마다 도구가 고른 후보 쪽(12~18쪽)만 봤다. 425쪽 보고서도 18쪽만 봤으므로 "이 보고서에 이 유형이 없다"고 말할 수 없고, 유형별 장수는 빈도가 아니다
- "잘 만들었다"의 판정은 수집자(Claude) 판단이다. 독자 시험을 거치지 않았다
- 글자 크기는 그림 안 글자가 PDF 글자 조각으로 남은 그림만 쟀다(그림 파일로 박힌 34장 안팎은 빠짐). 16cm 환산은 자른 상자 폭 기준이라 제목·여백이 들어간 만큼 작게 나온다
- 흰 바탕 비율은 보고서끼리 그대로 견주기 어렵다 — 옅은 회색 상자(#f6f6f6)는 흰 바탕으로, 조금 더 진한 상자(#f1f1f2)나 크림색 쪽 바탕은 칠한 면으로 잡힌다
- 지침서 4건의 규칙은 원문 쪽 번호와 함께 뽑았으나 긴 원문을 옮기지 않고 풀어 썼다. 지침서와 실제 보고서가 어긋나는 곳(제목 형식, 글자 크기)은 §3의 8번과 §2에 적었다
- 새 형태 15종으로 처음부터 그린 실제 문서 그림은 아직 없다. 예시는 모두 가상 수치다
