# 잘 그린 국내 공공 도식 벤치마크 (2026-10)

doc-figure v2.0의 근거 문서. "삽도를 그리라고 하면 디자인이 너무 구리다"는 피드백에 대응하려고, 실제 공공문서·제안서에서 **잘 그린 도식 57장**을 모아 재고, **사용자가 최종본에 채택한 그림 43장**과 대조했다. 그림 원본은 저작권 때문에 저장소에 넣지 않는다(로컬 `_private/benchmark-2026-10/`, git 제외). 여기에는 측정값과 규칙만 남긴다.

> 앞선 v1.3 벤치마크(`benchmark-classic.md`, FT·Economist·Tufte·국책연구기관 2010년대 인쇄본)는 "장식을 걷어라"는 방향이었다. 그 방향으로 만든 `report-classic` 산출물은 흰 바탕 93%·색 면적 1.7%로, 이번에 잰 잘 그린 도식(60%·17%)과 사용자 채택본(57%·16%) 어느 쪽과도 멀었다. **이 문서가 v1.3의 시각 절제 규칙을 대체한다.** 편집 관례(그림 번호·자료 표기, 없는 번호 붙이지 않기, 결론형 제목)는 v1.3을 그대로 따른다.

## 2. 수치로 본 차이

같은 잣대(그림 긴 변 900px로 줄인 뒤, 세 채널 모두 242 이상 = 흰 바탕, 최대−최소 채널 차 28 이상 = 유채색)로 쟀다. `render_figure.py --verify`의 "인상" 줄이 같은 계산이다.

| 묶음 | 흰 바탕 (중앙값) | 유채색 면적 (중앙값) |
|---|---|---|
| A 중앙부처 | 67% | 15% |
| B 연구기관 | 60% | 12% |
| C R&D 기획·예타 | 59% | 22% |
| D 해외 공공 | 65% | 20% |
| **잘 그린 도식 전체 57장** | **60%** | **17%** |
| E 사용자 채택본 43장 | 57% | 16% |
| 못 그린 사례 9장 | 12~86% | 6~67% (그라데이션·3D·무지개는 39~67%) |
| v1.3 `report-classic` 산출물 | **93%** | **1.7%** |
| v1.0 `gov-navy` 미리보기 27장 | 81% | 9% |
| v2.0 `board` 레시피 10장 | 40~63% | 14~29% |

못 그린 사례는 두 방향으로 벗어난다. 색이 과하거나(3D 도시·광택 구슬·무지개 행), 휑하다(장식 아이콘만 흩뿌린 콜라주 86%). **클립아트를 쓴 그림은 수치가 정상 범위(흰 69%·색 17%)에 들어오므로 수치만으로는 못 잡는다.** 눈으로 본다.

글자: 본문 도식의 글자는 인쇄 쪽에서 10~15pt(부처), 굵기 2단계, 크기 2~4단계, 전부 고딕. 그림 폭에 대한 본문 글자 높이로 환산하면 사용자 채택본이 1.5~2.2%, v1.x 템플릿이 0.9~1.3%였다(16cm 폭에 넣으면 4~6pt — 인쇄본에서 흐리고 휑해 보이는 원인 중 하나).

## 3. 반복해서 보인 시각 문법

괄호 안은 그 문법이 보인 장수 / 표본 수.

1. **두 층 채움 — 진한 머리띠 + 같은 색 옅은 몸** (A 11/15 · B 6/15 · C 9/15). 위계를 테두리가 아니라 칠한 면으로 만든다. 몸은 명도 90~97% 틴트.
2. **왼쪽 이름표 열** (A 6 · B 5 · C 6). 폭은 그림의 8~15%, 진한 단색 바탕에 흰 굵은 글자. 층위·행의 역할(비전·목표·전략, 응용·플랫폼·인프라)을 글보다 먼저 알린다.
3. **층마다 바뀌는 격자** (A 9/15). 같은 크기 상자를 같은 간격으로 늘어놓은 그림은 A·D 표본에 0장. 열 폭·알약 길이를 항목 수나 담당 범위에 비례시킨다(B 14 KIET 가치사슬).
4. **색에 정해진 뜻** (A 7 · B 13/15 · C 6). 범주·주체·층위·시간·상태 중 하나. 남색·청색 한 계열이 뼈대(A 10/15 · B 7/15), 둘째 색은 하나만 쓰고 역할을 고정한다(빨강=결론·문제·탈락, 노랑·주황=핵심 방향·주의). 회색은 현재·기존·배경, 진청은 목표(B). 같은 색의 명도 단계는 시간 순서나 상하위(B·C).
5. **상자 안의 구조** (C 9/15). 머리띠 + 글머리 목록, 번호 + 제목 + 설명, 목표 + 지표 줄 — 상자 하나에 2~3층이 들어간다. 라벨 하나만 든 상자와 정보량이 다르다.
6. **알약 머리·알약 태그** (A 7 · C 6). 열 머리, 연도, 사업명.
7. **번호 배지로 본문과 교차 참조** (A 7 · B 7). 번호는 본문이 매긴 것만.
8. **연결 기호와 관계 이름** (A 9/15). ▶ ≫ + 같은 기호로 잇고, 선 위에 "Enabler·Driver" 같은 관계 이름을 적는다. 해외 표본은 구슬 연결자·지시선으로 설명을 요소 옆에 붙인다(D).
9. **쉐브론(펜타곤) 단계** (B 3 · C 6). 연차 로드맵·절차. 지난 단계는 옅게, 도달 단계는 진하게.
10. **정량 지표 모듈** (C 5). '84 [2020] ➜ 90 [2025]' — 기준값→목표값, 목표값을 가장 크게.
11. **결론 한 문장 띠** (C 7). 그림 맨 위나 아래에 결론을 한 줄로.
12. **형태가 관계를 말한다** (D 12/12). 순환은 고리, 선별은 깔때기, 관통하는 기능은 허브, 사슬은 가로 화살 + 조건 띠, 연결망은 동심원. 같은 크기 상자 격자는 0장.

모서리: 보고서 본문 도식은 직각이 다수(B 12/15, A 본문 도식 곡선 0%), 발표 슬라이드형은 둥근 모서리(A 슬라이드 80~94%), 사용자 채택본은 6~16px 둥근 모서리. 그림자는 57장 중 1~2장, 그라데이션은 뜻이 있을 때(EU 자료 지연 띠) 한 장.

## 4. 사용자 채택본에서 잰 하우스 팔레트

사업 기획 흐름도(손배치 SVG)와 연구개발계획서 그림(PIL 손배치)이 따로 만들어졌는데도 거의 같은 값을 썼다. 이것을 `house` 프리셋으로 고정했다.

| 뜻 | 토큰 | 값 | 쓰임 |
|---|---|---|---|
| 본체·진행 | `--tone-main` | `#16275C` | 머리띠, 이름표 열, 진행 화살표, 결과 띠 |
| 보조 | `--tone-sub` | `#3D5BA9` | 두 번째 주체·범주, 일반 화살표 |
| 산출·통과·투입 | `--tone-go` | `#197D86` | 산출물, 판정 통과, 환류 |
| 주의·대기·예시 | `--tone-wait` | `#B77718` | 대기 구간, 횡단 점검, "설계 예시" 표시 |
| 탈락·제약 | `--tone-stop` | `#A84945` | 점선 상자(미통과·퇴출·제약) |
| 기존·관찰 | `--tone-mute` | `#6B778C` | 현재 상황, 관찰 대상, 비교 기준 |
| 옅은 바탕 | `--tone-*-tint` | 같은 색상 명도 94.5% | 카드 몸, 띠 바탕 |

채택본의 공통 배치: 결론형 왼쪽 제목(작은 머리말 + 굵은 제목, 왼쪽 색 막대) · 진한 띠(검토 항목·전제) → 옅은 카드 3열 → 주황 횡단 띠 → 옅은 결과 띠 · 아래 왼쪽 주석, 아래 오른쪽 범례 · 우상단 "설계 예시" 꼬리표.

이 사용자는 템플릿 그림을 "너무 별로"라며 거부하고 손배치 흐름도를 채택한 적이 있다(2026-09-30). 핵심 개념도는 **내용에 맞춰 배치를 새로 짠 그림**이 맞다 — `board`가 그 손배치를 사양 파일로 옮긴 것이다.

## 6. 따라 하지 말 것

그라데이션 부채꼴, 입체·광택 고리와 구슬, 3D 등각 도시, 클립아트·사진·휴대폰 목업, 배경 지도·흐림 구름, 행마다 바뀌는 무지개 색, 뜻 없는 반투명 버블, 라벨을 가리는 반투명 큰 숫자, 한 글자씩 세로쓰기, 저해상 래스터, 본문 7pt 미만.

## 7. 한계

- 표본은 공개 PDF에서 고른 57장이다. 행정안전부·디지털플랫폼정부위원회, IITP·NRF 자료는 첨부 형식(hwp)이나 링크 문제로 빠졌다. 2025~2026년 R&D 설명회 자료는 찾지 못했다.
- 래스터로 박힌 그림의 선 굵기·글꼴은 화면 근사치다.
- "잘 그렸다"의 판정은 수집자 판단이다. 수치(흰 바탕·색 면적)는 휑함과 과채색만 가르고, 클립아트·뜻 없는 색은 못 가른다.
- 사용자 채택본 중 일부는 이미지 모델 생성본이다(연구개발계획서 그림 일부). 그 생김새는 따르되, 한글 정확성·재현성 때문에 기본 경로는 코드 렌더로 둔다.
