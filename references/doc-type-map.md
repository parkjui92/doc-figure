# 문서 유형 → 템플릿·프리셋 매핑

> 형태 선택의 1차 기준은 문서 유형이 아니라 **그 자리의 의도와 관계 유형**이다 — [form-catalog.md](form-catalog.md). 아래 표는 문서 유형별로 자주 나오는 자리의 기본값이다.

문서를 받았을 때 "어디에 무엇을 그릴지" 정하는 출발점. **규칙이 아니라 기본값**이다. 본문이 다른 걸 요구하면 본문을 따른다.

## 유형별 기본 세트

> v2.0 — 제안서·계획서·보고서의 개념도·체계도는 **조립 도식(board) 레시피**가 먼저다. 잘 그린 국내 공공 도식 57장과 사용자 채택본 43장에서 잰 문법을 그대로 쓴다 — [benchmark-kr-2026.md](benchmark-kr-2026.md). 흑백 복사가 전제면 `report-classic`·`mono-formal`.

### 제안서 · 연구개발계획서 — 프리셋 `house`

평가위원이 짧은 시간에 훑는다. **일정·체계·차별성**이 그림으로 먼저 들어와야 한다.

| 들어갈 자리 | 레시피 / 템플릿 | 그림이 답하는 질문 |
|---|---|---|
| 비전·목표·전략 체계 | `board-vision-system` | 무엇을 위해 무엇을 하는가, 지표는 얼마인가 |
| 추진체계 | `board-governance` | 누가 책임지고 무엇을 주고받는가 |
| 추진 절차·연구 방법 | `board-process-tabs` · `board-research-framework` | 어떤 순서로, 무엇을 넣어 무엇을 내는가 |
| 연차별 추진 계획 | `board-roadmap` (월 단위면 `timeline-gantt`) | 기간 안에 어디까지 가는가 |
| 필요성·차별성 | `board-transition` | 지금 무엇이 모자라고 무엇이 달라지는가 |
| 운영 흐름·선정 절차 | `board-ops-flow` · `board-candidate-selection` | 무엇을 기준으로 거르고 어디로 보내는가 |
| 요구사항 대응 | `comparison-matrix` | 공고 요구를 빠짐없이 받았는가 |

### 공문서 · 내부 보고 — 프리셋 `mono-formal`

흑백 출력·팩스·복사를 거친다. 색으로 구분하는 그림은 살아남지 못한다.

| 들어갈 자리 | 템플릿 | 그림이 답하는 질문 |
|---|---|---|
| 사업 구조 | `structure-block` | 무엇이 무엇 위에 서 있는가 |
| 처리 절차 | `flow-process` | 어느 부서를 거쳐 어디서 끝나는가 |
| 대안 비교 | `comparison-matrix` | 무엇을 왜 고르는가 |
| 경과 | `timeline-tracks` | 제도와 사업이 어떻게 맞물려 왔는가 |

### 사업기획안 · 민간 제안 — 프리셋 `accent-plan`

읽는 사람이 결정권자다. **문제–해법–효과**가 한눈에 이어져야 한다.

| 들어갈 자리 | 템플릿 | 그림이 답하는 질문 |
|---|---|---|
| 사업 구조 | `layer-stack` | 우리가 놓는 층과 기존 층이 어떻게 붙는가 |
| 수단 비교 | `matrix-heatmap` | 어느 수단이 어디에 듣는가 |
| 병목 진단 | `pipe-mapping` | 지금 어디서 막혀 있고 무엇으로 뚫는가 |
| 선정·심사 | `decision-flow` | 무슨 기준으로 거르는가 |
| 추진 일정 | `timeline-gantt` | 언제 무엇이 나오는가 |

### 정책연구보고서 — 프리셋 `house-report` (흑백 복사가 전제면 `report-classic` · 환경·농정 `forest-green` · 과학기술 `teal-lab`)

| 들어갈 자리 | 템플릿 |
|---|---|
| 분석틀 | `concept-argument` · `structure-block` |
| 제도 경과 | `timeline-tracks` |
| 정책수단 평가 | `matrix-heatmap` |
| 대안 비교 | `comparison-matrix` |

### 학술논문 · 학위논문 — 프리셋 `academic-serif`

학술지 도판은 장식이 없고 흑백 인쇄를 견뎌야 한다. 외곽선 강조·명조 제목·왼쪽 캡션이 학술지 조판과 맞는다.

| 들어갈 자리 | 템플릿 |
|---|---|
| 분석틀·연구모형 | `concept-argument` · `structure-block` · `freeform`(경로·순환) |
| 사례 경과 | `timeline-tracks` |
| 사례 비교 | `comparison-matrix` · `matrix-heatmap` |

### 민간 기획 · 스타트업 · IR — 프리셋 `modern-charcoal`

| 들어갈 자리 | 템플릿 |
|---|---|
| 문제–해법 | `layer-stack` · `pipe-mapping` |
| 시장·전환 | `freeform`(깔때기) |
| 로드맵 | `timeline-gantt` |

### 자문 의견서 첨부 · 저가 인쇄 — 프리셋 `line-minimal`

채움이 거의 없어 복사·팩스·흑백에도 잘 남는다. `mono-formal`보다 가볍고 현대적이다.

## 프리셋 고르기 — 다양성은 문서 사이에서

- 한 문서 안에서는 **한 프리셋**. 다양성은 문서와 문서 사이에서 낸다
- 같은 발주처·같은 시리즈 문서는 같은 프리셋을 유지한다 (연속 간행물이 호마다 달라 보이면 안 된다)
- 사용자가 "다 비슷하다"고 하면: 같은 spec을 성격이 먼 프리셋 2~3벌(예: `academic-serif` · `modern-charcoal` · `teal-lab`)로 렌더해 나란히 보여주고 고르게 한다

## 몇 장이 적당한가

- **10쪽 미만** — 1~2장. 없어도 되면 넣지 않는다.
- **20~50쪽** — 4~6장. 장(章)마다 최대 1장.
- **50쪽 이상** — 6~10장.

문단을 그대로 옮긴 그림은 **분량만 늘리고 읽는 속도를 떨어뜨린다.** 서술로 충분하면 그리지 않는 게 낫다.

## 그릴 값어치가 있는지 판별

그릴 것:

- **관계가 2차원 이상**일 때 — 조직 계통, 시간×주체, 수단×영역
- **분기·순환**이 있을 때 — 통과/탈락, 환류 고리
- **세 개 이상을 나란히 비교**할 때
- 서술로 쓰면 **"위에서 말한 그"가 반복**될 때

그리지 말 것:

- 항목을 나열만 하는 것 → 글머리표로 충분하다
- 수치 두어 개 → 문장에 넣는다
- **본문에 없는 내용** → 그림으로 지어내지 않는다

## 프리셋 고르는 법

| 이 조건이면 | 프리셋 |
|---|---|
| 제안서·연구개발계획서·정책 보고자료 (컬러) | `house` |
| 연구보고서 본문 (컬러 인쇄) | `house-report` |
| 흑백 인쇄·팩스·복사를 거친다 | `mono-formal` |
| 정부·공공기관 양식이 v1.x 네이비 도식을 이미 쓰고 있다 | `gov-navy` |
| 화면·발표로 보여주고 결정을 받는다 | `accent-plan` |

**한 문서 안에서는 한 프리셋만 쓴다.**
